# Analisi delle prestazioni in Serie A

Progetto di tesi triennale sulla stagione 2020/21. L’analisi confronta le prestazioni tra giocatori e ruoli ed esplora le relazioni tra rendimento e valore di mercato con regressione, PCA e clustering.

Lo [script R](tesi_triennale.R) contiene i passaggi dell’analisi. Per eseguirlo in RStudio, usa questa cartella come directory di lavoro, procurati il foglio originale \`Statistiche_Calciatori.xls\` e installa i pacchetti indicati nello script. Il foglio dati non è incluso.
