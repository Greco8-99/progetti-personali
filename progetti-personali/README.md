# PROGETTI PERSONALI

Portfolio di progetti accademici di Gabriele Greco in analisi dati, visualizzazione e Data Science.

| Progetto | Cosa puoi vedere | Strumenti |
| --- | --- | --- |
| [Analisi esplorativa e reporting](tableau-analisi-esplorativa/) | Dashboard sulle sparatorie mortali da parte della polizia negli Stati Uniti e notebook di analisi | Python, Tableau |
| [Analisi delle prestazioni in Serie A](serie-a-analisi-statistica/) | Analisi univariata e multivariata dei calciatori della stagione 2020/21 | R, PCA, clustering, regressione |
| [Sintesi di documenti giuridici con RAG](rag-documenti-giuridici/) | Notebook di ricerca su sintesi estrattiva, ricerca semantica e generazione | Python, NLP, LLM |

I README dei singoli progetti descrivono i materiali disponibili e gli input richiesti per eseguire le analisi.
